B. JUDUL PROGRAM

Program menghitung luas persegi panjang.

C. DESKRIPSI MASALAH

Program ini dibuat untuk menghitung luas persegi panjang berdasarkan nilai panjang dan lebar yang dimasukkan oleh pengguna

D. TUJUAN PROGRAM

Membantu pengguna menghitung luas persegi panjang secara cepat dan tepat.9

E. ANALISIS INPUT, PROSES, DAN OUTPUT

1. INPUT:
  - input panjang persegi panjang
- input lebar persegi panjang
2. PROSES:
  - hitung luas persegi panjang
- rumus : L = p*l

3. OUTPUT:
   tampil hasil luas persegi panjang

F. ALGORITMA / PSEUDOCODE

MULAI

   1. Deklarasikan variabel panjang, lebar, dan luas.
   2. Masukkan nilai panjang.
   3. Masukkan nilai lebar.
   4. Hitumh luas persegi panjang (L=P*l).
   5. Tampilkan hasil luas persegi panjang.
